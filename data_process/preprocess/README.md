# Amazon preprocessing and SID construction

This folder contains the upstream GRRM scripts that filter Amazon-2014 or
Amazon-2018 interactions, construct item metadata, optionally synthesize
preference data, encode item text, and build residual-quantized SIDs.

The default SAGE reproduction does not execute these scripts. See the parent
[`README.md`](../README.md) for the expected order, optional dependencies, and
data-use boundary.
